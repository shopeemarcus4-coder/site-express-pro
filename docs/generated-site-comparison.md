# Dois sites gerados pela ferramenta de referência

Fonte: ZIPs `pamonhariadosimpro-site-gerado.zip` e `clnicadrsamuel-site-gerado.zip`, fornecidos pelo usuário em 23/10/2026. Cada ZIP contém somente um HTML. A análise abaixo é estática: scripts dos arquivos não foram executados e nenhuma chamada externa de rastreamento foi feita.

| Aspecto             | Pamonharia                                                                                                     | Clínica                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Composição          | Hero fotográfico, cardápio filtrável, promoção, destaque, história, galeria, avaliações, localização e dúvidas | Hero dividido, serviços assimétricos, etapas, autoridade, avaliações, localização e dúvidas |
| Mídia               | 24 elementos `img`, com URLs externas de Unsplash e Pexels; alguns destinos se repetem                         | 2 elementos `img`, ambos com URLs externas de Unsplash                                      |
| Paleta e tipografia | Verde `#153E23`, amarelo `#F3C94D`; Playfair Display e Plus Jakarta Sans                                       | Azul `#0F172A`, dourado `#C6A24B`; Cormorant Garamond e Inter                               |
| Interações no HTML  | Filtros, galeria com ampliação, transições de entrada, CTA de WhatsApp e mapa incorporado                      | Serviços em mosaico, transições de entrada, CTA de WhatsApp e mapa incorporado              |

Os dois HTMLs contêm um script de rastreamento que envia cliques a `landing-local-pro.preview.emergentagent.com`. Ele não é necessário para reproduzir o visual ou o fluxo. Ambos também apresentam avaliações numéricas, depoimentos, horários, selos e afirmações de experiência como se fossem fatos; os arquivos por si só não comprovam esses dados. A amostra da pamonharia inclui um item com nome de teste. O Site Express aproveita a estrutura visual e a navegação, mas só publica conteúdo preenchido e revisado pelo usuário.

Aplicações no gerador React: o modelo de serviços passa a destacar o primeiro serviço em uma composição assimétrica quando há pelo menos três itens; o bloco de contato mostra um mapa quando há endereço; a exportação HTML inclui metadados de compartilhamento e dados estruturados restritos aos campos informados. O site continua sem importar automaticamente fotos externas, avaliações, promoções ou scripts dos arquivos de referência.

Limite: os ZIPs não incluem imagens locais nem capturas de tela. As imagens dependem dos provedores externos; não é possível concluir a fidelidade visual final ou os direitos de uso a partir do HTML. O navegador Chromium desta máquina não concluiu uma captura local, então a validação visual ainda precisa ser feita em um navegador funcional.
